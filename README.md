**Cats vs Dogs Classifier using Deep Learning**

**Project Overview**

This project is a Cats vs Dogs Image Classifier developed using Deep Learning techniques in Google Colab. The model is trained to accurately classify images of cats and dogs using Convolutional Neural Networks (CNNs).

The purpose of this project is to understand the fundamentals of Computer Vision and how Deep Learning models can learn visual patterns from image data.

** Features**

Image classification using Deep Learning
Binary classification: Cats 🐱 vs Dogs 🐶
Data preprocessing and augmentation
CNN model training and evaluation
Prediction on custom images
Visualization of training accuracy and loss
